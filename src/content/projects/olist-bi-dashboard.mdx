## The Problem Context

In e-commerce logistics, the delta between estimated delivery time and actual delivery time directly correlates with customer churn and negative reviews. Utilizing the Brazilian e-commerce public dataset (Olist), the objective was to uncover hidden inefficiencies within the supply chain and test hypotheses regarding delivery performance.

Rather than just displaying raw metrics, this dashboard was designed to provide actionable insights for operations managers to preemptively address delayed shipments.

## Data Pipeline and ETL

Before any visualization could occur, the raw relational data required extensive processing. The Olist dataset consists of multiple fragmented CSVs (Orders, Customers, Reviews, Products) that needed to be unified.

The data cleaning phase involved:
* **Schema Alignment:** Standardizing primary and foreign keys across 5 disparate tables.
* **Deduplication & Imputation:** Handling missing geographical coordinates and resolving duplicate order entries to ensure absolute data integrity.
* **Feature Engineering:** Calculating the actual delivery duration versus the estimated duration to create a `delay_variance` metric.

## Hypothesis Testing: Linear Regression
